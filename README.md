# ticketsmaster

The best tickets selling website in the US

TicketFlow — a small single-page demo showing live events, filtering and booking UI.

## How to run

- Clone the repo:

  git clone https://github.com/kimkimathi52-hue/ticketsmaster.git
- Switch to the branch (if you created it locally):

  git checkout extract/readme-to-files
- Open index.html in your browser:

  open index.html
  or

  python -m http.server 8000

  then visit http://localhost:8000


## Notes

- The UI uses Google Fonts and Font Awesome from CDNs.
- This repo previously stored the demo app in README.md. The app has been extracted into:
  - index.html
  - assets/css/styles.css
  - assets/js/app.js
